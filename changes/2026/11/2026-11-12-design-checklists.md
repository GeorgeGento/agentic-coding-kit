# Design brief per project, anti-slop and hand-over checklists

- `guidelines/ux-ui-seo.md`: each project keeps one standing design brief (`docs/design-brief.md`) that every UI task reads; a project with UI and no brief gets one before its next visual change. New **Anti-slop checklist** and **Before handing over** checklist.
- `roles/ui-ux.md` and `roles/executor.md` point at the project brief and both checklists.

## Changes to existing behaviour

UI work is not done until both checklists are ticked; the `ui-ux` reviewer reports each miss as a finding. Ideas borrowed (not the package) from ui-ux-pro-max-skill: a persisted per-project design file and named anti-patterns.
